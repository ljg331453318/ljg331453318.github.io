# SCI 投稿择时与历史学习

这是一项传统文化体验和自报数据实验，尚无证据证明其能提高 SCI 录用率。

## 时间与候选

出生排盘、当前问询起卦与候选时刻统一使用北京时间 UTC+8。问询时刻由点击测算时自动取得；向后枚举 60 天的传统时辰，子时跨民用日拆分。只在日、时均黄道且日、时支与四柱地支未见六冲的时段中选取三个不同日期。不宣称分钟级预测。

未启用历史模型时，排序完全由 `submission-engine.js` 的明确传统规则决定。模型启用后，对符合筛选条件的候选池按模型参考分排序；分数不作为个人录用概率展示。

## 私有记录

`/dao/submission-list|save|delete` 沿用修习凭证的 Bearer 身份验证。查询、更新、删除只作用于凭证所有者自己的记录。首次保存的问询参照、计划时段及算法版本不可被更新覆盖，实际投稿与最终决定另记。

只保存派生日主、四柱地支、问询时刻、计划时段、实际时刻、结果、决定时刻、研究领域、JCR 分区和投稿阶段；不保存原始出生年月日时、姓名或论文题目。别名限制 40 字。记录不向其他用户展示。默认不同意学习，用户可撤回同意或删除记录。

计划、等待、录用、拒稿和撤稿均可记录。只有明确同意的录用 / 拒稿案例作训练标签。特征由服务端依据实际投稿时刻重算，忽略客户端上传的特征。服务端拒绝未来的实际投稿及决定时刻。

## 实验模型

`submission-learning.js` 使用扩展卡尔曼更新的逻辑分类模型（EKF 是非线性 Bernoulli 观测的近似更新）。这属于机器学习，没有接入大语言模型。32 维特征包含时刻、星期、传统参照与领域、分区、投稿阶段。不训练原始出生日期。

模型接口只返回统计、验证指标和通过门槛后的模型权重，不返回其他作者的记录。当前使用最近 2,000 份获同意的结案记录。数据未通过门槛时不返回可用模型，前端不参与历史排序。

本站预设的实验门槛：

- 结案至少 400 份；录用与拒稿各至少 80 份；至少 30 个不同匿名凭证。
- 按实际投稿时刻留出末段约 25% 验证；训练排除所有验证作者，以及验证截点时尚未知结果的案例。
- 训练至少 200 份，验证至少 100 份且含至少 20 个不同凭证；训练和验证均须包含足够正负样本。
- 留出 Brier 误差比训练集录用比例基线降低至少 5%；按作者聚合误差差值的近似 95% 上界须小于零。
- 只使用已评估的冻结权重，不在通过验证后用验证标签重新拟合。

门槛是工程约定，不构成统计有效性认证。匿名凭证不是经过核验的真人作者，结果也未经期刊核验。用户选择、稿件质量、期刊差异、延迟结案和重复验证均可能引入偏差；通过上述门槛仍不能推断择时的因果效果。

## 验证与部署

使用 Node.js 24：`node --test tests/submission.test.mjs`。覆盖候选时间边界、冷启动、不平衡标签、作者隔离、决定时间泄漏、已知合成信号、所有权、计划保留、撤回同意和服务器重算特征。合成数据仅用于内存测试，不上传线上学习库。

D1 增量结构为 `counter-worker/submission-schema.sql`，不修改既有修习进度与公共庭院数据。先执行该文件，再部署现有 Worker；静态文件仍由 GitHub Pages 发布。
